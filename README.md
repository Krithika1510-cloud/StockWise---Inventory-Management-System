# StockWise---Inventory-Management-System
StockWise is a web-based Inventory Management System built using HTML, CSS, and JavaScript. It allows users to add, edit, delete, search, sort, and export product records. It also demonstrates DSA concepts such as Linear Search, Binary Search, Merge Sort, and Binary Search Tree (BST), with Local Storage for data persistence.

##  Features
- Admin Login
- Interactive Dashboard
- Add New Products
- Edit and Delete Product Details
- Search Products by Name, Category, or SKU
- Sort Inventory Records
- Export Inventory Data as CSV
- Monitor Low-Stock and Out-of-Stock Products
- Store Data Using Browser Local Storage

##  Data Structures and Algorithms Used

1. Linear Search
Searches for products by checking records one by one.

2. Binary Search
Searches for products using their numeric SKU.

3. Merge Sort
Sorts product records efficiently using the divide-and-conquer technique.

4. Binary Search Tree (BST)
Stores product SKUs and supports searching and tree traversal.

##  Technologies Used
- HTML – Structure
- CSS – Styling and responsive layout
- JavaScript – Functionality and algorithm implementation
- Local Storage – Browser-based data persistence
