Algorithm notes for viva

Brief explanation you can use during the project demonstration.

ConceptHow it is usedTypical complexity
BSTStores numeric product SKUs; inorder traversal displays them in ascending order.Average insert/search O(log n), worst O(n)
Linear searchChecks each product's name, SKU, and category until it finds a match.O(n)
Binary searchFinds an exact numeric SKU in a list sorted by SKU.O(log n)
Merge sortDivides the list, sorts each half, and merges the halves.O(n log n)
